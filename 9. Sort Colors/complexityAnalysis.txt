🧩 Problem: Sort Colors

Difficulty: Medium

The task is to sort an array containing only 0s, 1s, and 2s (representing red, white, and blue respectively) in-place and without 
using built-in sort functions. The colors should appear in order: red (0), white (1), and blue (2).

🥉 Approach 1: Brute Force (Using Counting)
Logic:
-Count how many 0s, 1s, and 2s are present in the array.
-Then overwrite the array by placing that many 0s, then 1s, then 2s.

def sortColors(nums):
    count0 = count1 = count2 = 0

    # Step 1: Count how many 0s, 1s, and 2s
    for num in nums:
        if num == 0:
            count0 += 1
        elif num == 1:
            count1 += 1
        else:
            count2 += 1

    # Step 2: Overwrite the array in order
    i = 0
    for _ in range(count0):
        nums[i] = 0
        i += 1
    for _ in range(count1):
        nums[i] = 1
        i += 1
    for _ in range(count2):
        nums[i] = 2
        i += 1
